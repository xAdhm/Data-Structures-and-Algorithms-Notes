# Course Completion - Next Steps and Further Learning

Closing article of the interview prep course — marks the end of the core curriculum covered throughout this vault.

## The three-part mastery checklist, per topic
For each chapter/topic covered in this course, aim to:
1. Be comfortable **implementing** it in your preferred language
2. Understand the **time and space complexity** of its basic operations
3. Know its **advantages** and recognize **when to use it**

## Recommended approach going forward
- **Focus on one topic at a time** — solid understanding of a topic tends to stick long-term once achieved.
- **Solve 5–10 problems per topic** (or more, until comfortable) — the bonus problems at the end of each chapter are a good starting point.
- **If stuck on a problem:** don't stare at it for an hour. Read an official solution or discussion write-up, make sure the algorithm is **fully** understood, move on, then revisit the original problem after a few days to a week.

## Further learning — topics not covered in this course

**Less common than what was covered, but still worth knowing if time permits:**
- Union Find
- Topological Sort
- Quickselect
- Radix sort / Pigeonhole principle
- Minimum spanning tree (Kruskal's)

**More advanced, unlikely to show up in a typical interview:**
- Fenwick tree
- Segment tree
- Suffix tree
- Bellman-Ford (or other non-Dijkstra's shortest path algorithms) — relevant context: [[Dijkstra's Algorithm - Overview]] only handles graphs without negative weight cycles; Bellman-Ford is the classic algorithm that handles negative weights correctly.
- Rolling hash / Rabin-Karp / KMP
